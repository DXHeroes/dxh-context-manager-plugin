# {{PROJECT_NAME}}: decisions

*The decisions taken in this project, each with its why, so that no session reopens a settled question without knowing why it was settled.*

Record a decision when it is hard to reverse, surprising without context and the result of a real trade-off, all three. Record it also when agents keep proposing the opposite. Newest first. Numbers are never reused. A decision that no longer holds is not deleted: a new entry supersedes it, and the old entry's status says so.

Each entry in this shape:

```
## NNN - <YYYY-MM-DD> - <the decision in a few words>
- Status: accepted (or: superseded by NNN)
- Context: what led to it, with the source
- Decision: what was decided
- Consequences: what follows from it, and what was rejected
```
