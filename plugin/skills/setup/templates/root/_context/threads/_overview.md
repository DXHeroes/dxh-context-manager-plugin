# This root: threads

*The index of what was discussed here, so that a later session can find an earlier conversation without reading them all.*

Context is what is true, threads are what we discussed. The files beside this one hold the conversations: the user's words near verbatim, your output compressed to decisions, reasoning, outcomes and open questions.

One file per topic, named `NNN-<slug>.md` with the next free number, frontmatter `type: thread`, `title:`, `started:` and `updated:`, and one dated section per session. A thread spans sessions. Past about 200 lines, the older sessions are compacted to their outcomes and the recent two or three stay in full.

Each thread has one row below. Status is `open` while the topic is live and `closed` when it has ended. Last session is the date of its newest section.
