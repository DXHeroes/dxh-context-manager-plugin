# About

*Who the user is, where they work and how, so that every task, even a small one, is done for this person and not for anyone at all.*

Filled at the first opening and copied into every new project. After that each copy is its own: a change here does not reach the projects, and a change in a project does not come back. What a project is about lives in that project's state, not here.

The git switch is `git:` in the frontmatter. `ask` means the first opening asks, `on` means clean up and handoff commit when the folder is a repository, `off` means git is never touched. The user may change it by hand at any time. The language switch is `language:`: `ask` means the first opening asks, any other value is the language you talk to the user in.
